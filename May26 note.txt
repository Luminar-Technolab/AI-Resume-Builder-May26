            JAVSCRIPT
    --------------------------

    1. JS is a programming language used to make web page interactive. It also runs in browsers as well as servers using Node js.
    2. Node js - Runtime environment for js outside the browser
    3. Basics of JAVSCRIPT
        - Display contents : console.log(contents) 
        - Data types in js : use 'typeof' keyword to check data type of a data
            - Primitive Data types : Used to store only single value
                - String, Number, Boolean, undefined
            - Non Primitive Data types : Used to store multiple values
                - Array, Object, Function
        - Variable : Used to store data
            - Create Variable using var, const, let keyword
            - Variable using var : Syntax - var Identifier = value, It can be Hoisted with 'undefined', Value can reassigned, GLobal scope
            - Variable using const : Syntax - const Identifier = value, Value can not changed, Hoisted but no initial value, Block scope
            - Variable using let : Syntax - let Identifier = value,  Value can be changed, Hoisted but no initial value, Block scope
        - Concantention : Joining different/same type of data using + operator
        - Hoisting : Moving declaration code to the top before it execution, its default behaviour of JS
            - Variable 
        - Template Literals : Used to combine different type of datas, using back tick to give the entire data, to give Variable use ${}
        - Type Coercion : Is the automatic or explicit conversion of a value from one type to another
        - Operators in JS
            - Assignment operator : =
            - Arithmetic operator : + - / * % ** , it gives only number
            - Relational operator : > >= < <= == != === , it gives only Boolean
            - Logical operator : && || , it gives only Boolean
                    &&              ||
                  T && T = T      T || T = T   
                  T && F = F      T || F = T   
                  F && T = F      F || T = T
                  F && F = F      F || F = F  
            - Increment / Decrement operator : ++ --, canbe used pre & post
            - Shorthand operators : += -= : x = x+y => x += y
            - Ternary operator : Syntax - condition ? Statements when condition true : Statements when condition false, Alternative to if-else Statements
            - Truthy operator : Syntax - condition && Statements when condition true, Alternative if Statements
            - Spread operator (...) : used to expand the iterating varible (string, array) into a single element
            - Rest operator (...) : used to collect multiple elements into single array/object, Used in function parameters and object Destrucring
        - Conditional Statements : Used make decision based on condition
            - if Statements : Syntax - if(condition){ step to execute when condition become true }
            - if-else Statements : Syntax - if(condition){ step to execute when condition become true }else { step to execute when condition become false }
            - else-if Statements
            - switch Statements : Syntax : switch(condition){ case answer: Statements; break;default : Statements }
        - Looping Statements : Used to repeat same task multiple times
            - while loop (Entry Controlled Loop) : Syntax
                1. initialise a Variable
                2. while(condition use initialised Variable){
                3.    steps to be repeated execute when condition become true
                4. Change the value of Variable used in condition
                }
            - for loop (Entry Controlled Loop) : Syntax
                for(initialise a Variable;condition use initialised Variable;Change the value of Variable used in condition){
                     steps to be repeated execute when condition become true
                }
            - break & continue Statements
                - break Statements : used to exit forcefully from a loop
                - continue Statements : used to skip the condition in loop
            - Nested Loop : Used to define a loop inside another loop
                - Basic Structure
                    outer loop{
                        inner loop {
                           first execution completes
                        }
                    }
                - Used to display pattern, Matrics etc
        - Functions : Used to perform specific task in a code 
            - JS Functions : Consist of 2 parts - Function Defintion, Function Call
            - Function Defintion : used to define the task , can be hoisted
                - Syntax : function function-name(arguments){
                    steps to perform task
                }
                - return Statements : used to return data from function Defintion to its function call. its often used as the last statement in function definition
            - Function call : used to execute the task
                - Syntax : function-name(parameters)
            - Diffrent types of Functions
                - Predefined functions : Already defined functions, ex: Math.floor(), console.log() etc...
                - Arrow functions : Alternative for normal function definition. Cannot be hoisted
                    - Syntax : const/var/let function-name = (arguments)=>{ steps to perform task}
                - Callback function : Defining a function inside another function call
                    - Syntax : function-name(function definition)
                - Anonymous function : are self executing function
                - Recurssive function : Similar to repeating function / loop, Calling the function inisde its own definition
                - Nested functions : Defining a function inside another function definition
                - Currying functions : Technique of making multi argument function into sequence of single argument function, so inner most function uses closure property to perform task
            - Closure property : In nested function, child function can access parent data and its local varible
            - Default parameters : js allow to assign default value to a function parameter. If a caller doesnot provide a value then default value is used.
        - Array : Used to store multiple values in a single varible, using [] to provide multiple values
            - index : used to access array items, it starts from 0, Syntax : array-name[index]
            - length : used to find total items in an array
            - Array Methods : Syntax - array-name.method-name()
                - push() / unshift() : insert values at end / start in an array
                - pop() / shift() : remove value of an array from end / start
                - sort(comparisonFun) : used to sort array items, a-b : ascending order, b-a descending order
                - forEach(Callback function) : used to fetch array item one by one, Similar to for-of loop
                - map(Callback function) : used to map each array item with a mapping function and return a new array with its result
                - filter(Callback function) : used to get the items from an array which satisfy the condition and return an array
                - find(Callback function) : used to get the first item from an array which satisfy the condition 
                - reduce(Callback function) : used to find last least, highest / total value from an array
                - reduceRight(Callback function) : used to find first least, highest / total value from an array 
                - some(Callback) : used to get a boolean (true /flase) from an array after applying condition, if any one of the item satisfy the condition then it returns 'true' otherwise false.
                - every(Callback) : used to get a boolean (true /flase) from an array after applying condition, if all items satisfy the condition then it returns 'true' otherwise false.
                - flat(depth/Infinity) : used to flattened array based on its depth, if depth is infinity then it returns always a single dimensional array
                - includes(value) : used to check a value is in the given array or not
                - indexOf(value) : used to get index of value in array otherwise it return -1
                - splice(startIndex,deleteCOunt) : used to delete item with index as startIndex from given array
                - reverse() : used to reverse item of an array
                - concat() : used to join 2 array and return new array with all combined items
                - join(sepeator) : used to combine all array item into a single string seperated by given seperator
                - slice(start,end) : used to extract items fro  given index to new array
        - String : Collection characters inside single/double quotes
            - String Methods
                - length : used to find numbers of charcters in a string
                - chartAt(index) : used to return character in stored in the given index
                - slice(start,end) : used to extract characters from given start and end range, if end value is negative then last charcters removed according to that value
                - substring() : used extract part of  a given string
                - split() : used split string into array based on the seperaters
                - includes(value) : check a value is part of string, return boolean
                - startsWith(value) : check a string is starts with given value
                - endsWith(value) : check a string is end with given value
                - toLowerCase()
                - toUpperCase()
                - trim() : remove space from starting /ending of a string
        - Object : Used to store multiple data as key-value pair inside curly braces, any type (string,number,boolean,array, function) of data can be stored in object
            - To Access values from an Object using its key
                - Using Bracket Notation : Object-name['key-name']
                - Using Dot Notation : Object-name.key
            - Check Key is in Object
                - hasOwnProperty() : used to check a key is in an object or not, Syntax : object-name.hasOwnProperty('key-name')
                - 'in' operator : used to check a key is in an object or not, Syntax : key-name in object-name
            - Insert/Update a value in an exsting object : use assignment operator, if key is present in object then its value get updated otherwise insert it as new key-value pair
                - object-name['key-name'] = value / object-name.key = value
            - To get all keys : Object.keys(object-name) : it returns array with key present in the object
            - To get all values : Object.values(object-name) : it returns array with value present in the object
            - To remove object property (key-value pair) using delete keyword, Syntax: delete object-name.key
        - Exception Handling : Handling run time errors, try & catch block, place codes which causes errors inside try block and its immeadiate catch block used to solve the errors
        - OOPs (Object Oriented Programming) : Is a style Writing programs, OOPs related to real world scenarois, 
            - Key Parts OOPs
                - Object : Similar to real world entity, used to access class property/ methods outside a class, 
                    - create object : new class-name() it return object foe the class 
                - Class : Blueprint of Object, use 'class' keyword to create js class. Inside class, we can see only property & methods
                    - constructor method : used to initially assign values to a class property
                - Reference : Used to connect class with object, this keyword
            - Key Features 
                - Inheritance : Reuse of code from another class, 
                    - Classical Inheritance : use 'extends' keyword for Inheritance
                    - Prototype Inheritance : used to inherit between objects, use '__proto__' keyword
                - Polymorphism : use same methods in different Ways
                - Abstraction : Showing only esstial fetaures and hide complex implementaion
                - Encapsulation : Budling data and methods together and control the data
        - ES6 - Features 
            - Variable - var,const, let
            - Hoisting
            - Template Literals  
            - Arrow functions
            - Closure
            - Default parameters
            - Destrucring of Arrays & Objects
            - Modules : using import & export Statements

        - Inline event binding : same line html tag event-name=function call
        - Using DOM Property : 
        - using 'addEventListener' method : bind multiple Events to an element
    8. Browser Storages : It allows web apps to store data in users browser for persistence 
        - Local Storage : It has a capacity of 5-10 MB, Never expires untill we manually removes
        - Session Storage : It has a capacity of 5 MB, Data expires when we close the tab or browser
        - Cookies : It has a capacity of 4 KB, Based on expires date, used to store data from another app 
        - IndexedDB : Hundreds of MB to GB, 
        - Storage Methods in Local / Session Storage
            - setItem(key,value) : used to store data to a browser Storage, Both key & value should be in string
            - getItem(key) : used to get a data from Storage

            - clear() : used to remove all data
            - JSON.stringify(value) : used to convert value to string
            - JSON.parse(value) : used to parse data to its original type
    9. Handling functions in js : Javascript uses single thread to execute functions
        - Synchronous functions : Function executes line by line, Each statement waits for completing previous one, It follows blocking model execution
        - Asynchronous functions : Allows other code to run while waiting for a time-consuming task (such as timer, API, file reads etc...) to complete.
        - Call Stack : Used to handle functions inside js Engine, There is only one call stack to handle function (LIFO : Last in First out), If stack is busy, other task should be wait
        - Web API (setTimeout, setInterval, fetch,DOM events (click, dbclick, mouse /keyboard related events),Geolocation) provide by Browser. 
        - Callback Queue / Macrotask Queue : Used to store Asynchronous functions like setTimeout,setInterval 
        - Microtask Queue : used to store API call, it has higher priority than Callback Queue
        - Event Loop : is an infinite loop used to check
            - is the call stack is empty
            - if yes, execute all task in Microtask Queue
            - then execute one task from Callback Queue
            - Repeat
    10. Handling Asynchronous functions using js
        - Using Callback function : it can handle Asynchronous function but nesting of callbacks leads to callback hell (Output wont be recieved)
        - Using Promise : it used to handle Asynchronous function , it always return response either a success or a failed, JS uses Promise object, it has different state
            - Pending : when we make Asynchronous call before it resolves
            - Resolved/fullfilled : indicate response recieved from Promise, to access resolved state in js using 'then' method
            - Reject : indicate Promise failed, to access reject state in js using 'catch' method
        - Using async & await keyword : async/await used to make Asynchronous code to look like Synchronous, async keyword used to make a function Asynchronous, inside Asynchronous function we can use await keyword. it returs fullfilled / resolved state of promise when await, use try-catch block to get reject state in async/await
    11. API (Application Programming Interface) : Used to make communication between different application available in internet
        - Different type of API Architecture
            - REST API : use HTTP protocol, JSON type data tobe transfered
            - SOAP API : use HTTP protocol, XML type data
            - WEB SOCKETS
            - GRAPHQL
        - URL (Uniform Resource Locator)
            - ex: https://jsonplaceholder.typicode.com/users/3
            - BaseURL : https://jsonplaceholder.typicode.com
            - URI (Uniform Resource Identifier) : https://jsonplaceholder.typicode.com/users
            - Path Parameter : Dynamic part of URL , ex: 3
            - Query Parameter : content follwed with ? mark in URL, it always in key=value format
        - HTTP (Hyper Text Transfer Protocol)
            - Request : consist of 'header' part and a 'body' part
                - header part : keep secret data
                - body part : used to share data from one app to another
                - Requests (GET, POST, PUT, DELETE)
            - Response : Every response contain a status code
                - 1xx : Information
                - 2xx : success
                - 3xx : Redirection
                - 4xx : Failed due to Client errors
                - 5xx : Failed due to Server errors
        - JSON (Javascript Object Notation) : is a format used to transfer data from one app to another in internet
            - format : {"key":value}
        - API Testing Tools
            - Postman
            - Thunderclient extension in VS code
    12. API Call using Javascript (AJAX - Asynchronous Javascript XML)
        - API Call using XMLHttpRequest : Is a standard way of using AJAX

            - To send the request use 'send' method of XMLHttpRequest class
            - XMLHttpRequest 'readystate' property will change when send the request
            - If readystate is 4 then we got response from server

        - API call using 'fetch' method

        REACT - FRONTEND TECHNOLOGIES
    --------------------------------------

    1. React is Javascript library used to build dynamic user interfaces especially for a single page application
        - Developed by Meta 
        - First released in 2013
        - Open-source & component based 
        - Use Javascript & JSX
    2. Features of React
        - Component based Architecture
        - Virtual DOM : Lightweight memory representation of DOM, Reconciliation used to find change in the Virtual dom 
        - JSX (Javascript XML) : used to write HTML code in js
        - One way Binding : Parent only share data to child component and vise verse is not possible
        - Declarative UI : means describing UI for a given data while react take care of how to update the data in browser
        - Fast Performance
    3. React Project Creation : using vite 
        - command for creating react project using vite : npm create vite@latest react-project-name -- --template react
        - run project  : 'npm run dev' in react project command prompt, use port 5173 to view the output in browser
    4. Files & Folder Structure
        - vite.config.js : used to define vite configuaration
        - README.md : used to document the project
        - package.json : configuaration file npm for project 
        - package-lock.json : used to store all installed package version details of a project
        - eslint.config.js : configuaration file for eslint, & used to check code errors, bugs,style errors etc
        - .gitignore : used to store file/folder should be avoided while adding git
        - index.html : entry point of your react app 
        - node_modules : used to store dependent/installed package details of project, to create node_modules use command : npm install
        - public : used to store contents available anywhere in project, use the public content without importing
        - src folder : used to provide react project logic 
            - assets folder : used to store assets (image, pdf file etc) of a project
            - main.jsx : used to decide which component should displayed in index.html page, createRoot methods lets you create a root to display React components inside a browser DOM node.
            - index.css / App.css : css file used for styling

    8. Lifecycle Phases of React components : Describes different phases of component experience during its Mounting (creation), Upating (updation) and UnMounting (deletion), LC phases are only for CLass based components
        - Mounting : Component created and insert into DOM (component creation --> Render JSX --> Insert to DOM --> Display in Browser )
        - Updating : Component detect change, REact compare old Virtual dom with new Virtual dom and apply reload only at the change part of DOM ( component mounted --> identify changes (props/state) --> component re render --> UI updated )
        - UnMounting : Removing component from DOM. (Component removed --> component unmounted )

    11. Hooks : are predefined functions used in functionnal component inorder to use react component fetaures in functionnal component, all hook function name are startsWith 'use' keyword, multiple hooks are available in react for each react component features
        - Rules to call Hooks functionnal component
            - Import the hooks 
            - Hooks should be used in top level of component
            - Hooks can not be conditional
        - Common Predefined Hooks
            - useState : hook used to create state in functionnal component and it Returns a stateful value, and a function to update it. Inorder to update state call state updating function with argument as the new value. Syntax : const [statefulValue, state updating function]= useState(initialValue)
            - useEffect : used to apply side effects to a functionnal component, it also can be used to get component life cycle methods in functionnal component. Syntax : useEffect(callback function, dependency)
                - dependency can be of different types
                    - no dependency : side effects will apply to the component all the times, 
                    - empty array : side effects will apply at the time of component creation, Similar to Mouting phases
                    - [state/props/variable] : side effects will apply at the time of component creation as well as whenever state/props/variable given in the array changes. Similar to Updating
            - useRef : used to refer real dom elememnt it wont allow re rendering component when its value changes, Syntax : const refData  = useRef(), it returns Reference of a DOM elememnt and it is an object, its 'current' key will gives us the details which dom elememnt it fetched
            - useMemo : used to memorise expensive calculation result of a component and only perform when its dependency changes, Hook returns a value, Syntax : useMemo(()=>{ expensive calculation steps},[dependency]), 
                - dependency can be of different types
                    - empty array : useMemo works only at the creation of component
                    - array with state/props : useMemo works when the state / props value changes
            - useCallback : used to memorise expensive calculation function of a component and only perform when its dependency changes, Hook returns a function, Syntax : useCallback(()=>{ expensive calculation steps},[dependency])
        - Custom Hooks : userdefined hooks , create a js file with name startsWith use keyword, define  a function and export same
